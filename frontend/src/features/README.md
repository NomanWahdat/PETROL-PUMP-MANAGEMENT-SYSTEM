Implemented features include authentication/session selection, shared station profile/branding, configuration schemas, and operational fuel workflows. `operations` contains the simple attendant shift/sale/payment flow, management ledgers, stock screens, daily closing and printable receipts. See ../../../docs/architecture.md and ../../../docs/phase-3.md for boundaries and API conventions. Accounting reports and durable offline recovery remain for later phases. Authoritative meter, stock, debt and money calculations belong to backend services; components display server quotes and results.
